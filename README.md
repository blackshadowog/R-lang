# 📦 Installation

Install R from:

https://cran.r-project.org/

Install RStudio from:

https://posit.co/download/rstudio/

Then install the commonly used packages:

```r
install.packages(c(
  "dplyr",
  "tidyr",
  "ggplot2",
  "readxl",
  "writexl",
  "jsonlite",
  "DBI",
  "RSQLite"
))
```

---

# ▶️ How to Run

Open any `.R` file in **RStudio** and click:

**Run → Run All**

Or execute a file from the R console:

```r
source("01_file_name.R")
```

For example:

```r
source("70_data_analysis_project.R")
```

# ⭐ How to Use This Repository

Don't just copy and run the programs.

For every code:

1. Read the comments.
2. Run the program.
3. Understand the output.
4. Change the values.
5. Break the code intentionally.
6. Fix the errors.
7. Add your own features.
8. Build a small variation of the program.

**The real learning happens when you modify the code yourself.**
