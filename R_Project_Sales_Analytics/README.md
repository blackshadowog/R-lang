# R Sales Analytics Project

A complete beginner-to-intermediate R Data Analytics project.

## Workflow

Data Generation → Data Cleaning → EDA → KPI Analysis → Product Analysis → Regional Analysis → Visualization → Regression → Business Insights

## Requirements

Install R/RStudio and run:

```r
install.packages(c("dplyr","ggplot2"))
```

## Run

Open `main.R` in RStudio and click **Run**.

## Project KPIs

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Best Product
- Best Region
- Monthly Revenue

## Output

The program creates:

- `data/sales_data.csv`
- `output/product_summary.csv`
- `output/region_summary.csv`
- `output/monthly_summary.csv`
- Revenue/product chart
- Revenue/region chart
- Monthly revenue chart
- Quantity/revenue regression chart

## Skills Practiced

R, data frames, CSV, data cleaning, dplyr, ggplot2, grouping, summarisation, KPIs, visualization and linear regression.
