# Data Dictionary

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Age | Customer age |
| Gender | Customer gender category |
| City | Customer city |
| PreferredChannel | Main purchase channel |
| RecencyDays | Days since most recent purchase |
| PurchaseFrequency | Number of purchases |
| MonetaryValue | Total customer monetary value |
| TrueSegment | Synthetic reference segment; not used by K-Means |
