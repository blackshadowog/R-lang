# Project #3 — Sales Forecasting

A portfolio-ready time-series forecasting project using Holt-Winters Exponential Smoothing.

## Objective
Forecast future monthly sales from historical trend and seasonal patterns.

## Dataset
60 months of synthetic monthly sales data from 2021–2025, including Sales, Orders and Customers.

## Methodology
- Data preparation and EDA
- Monthly time-series setup
- 12-month holdout validation
- Holt-Winters trend + seasonality
- MAE and RMSE evaluation
- 12-month future forecast
